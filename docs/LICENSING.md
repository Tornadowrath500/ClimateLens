# Licensing decision

No license has been added to the FairLens source code yet.

The UCI dataset has its own CC BY 4.0 license. That does not decide the license for this repository's code.

Before adding a project license, all contributors should agree on:
- whether the code is intended to be reused commercially;
- whether attribution requirements are sufficient;
- whether any third-party code or assets introduce additional terms.

Do not assume the dataset license and repository software license are interchangeable. Once the team agrees, add the chosen license text at the repository root and update this page.
